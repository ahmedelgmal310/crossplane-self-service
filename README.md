# crossplane-self-service

[![CI](https://github.com/ahmedelgmal310/crossplane-self-service/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/ahmedelgmal310/crossplane-self-service/actions/workflows/ci.yml)

A self-service internal developer platform built on Crossplane v2. A developer asks for a
complete environment with one small YAML claim; the platform creates the namespace, quota,
network policy, PostgreSQL database, credentials and application.

Documentation is being written; see the CI workflow for what is tested.
